# Global Intelligence Source Catalog (GISC)

## Overview

The Global Intelligence Source Catalog (GISC) is the master intelligence database for CryptoIntel OS.

Every intelligence collector must originate from this catalog.

No collector should ever be built without first documenting its source here.

---

## Objectives

The catalog exists to answer four questions:

1. Where can intelligence be collected?
2. What kind of intelligence does the source provide?
3. How reliable is the source?
4. How should CryptoIntel OS collect from it?

## Source Documentation Standard

Every documented source must include:

- Name
- Official URL
- Description
- Intelligence Category
- Access Method
- Authentication
- Rate Limits
- Reliability
- Priority
- Supported Chains
- Data Produced
- Future Collector
- Evidence Weight
