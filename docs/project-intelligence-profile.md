# Unified Project Intelligence Profile

## Profile philosophy

`ProjectIntelligenceProfile` is the immutable canonical output representing everything CryptoIntel OS currently knows about one project. It composes existing identity, evidence, findings, assessments, signals, relationships, provenance, and traceability without rewriting or inferring source intelligence.

## Canonical output

The profile contains the canonical project identifier, `IdentityBundle`, `UnifiedEvidenceBundle`, `ProjectFindingGroup`, `ProjectAssessmentGroup`, canonical signals, relationships, provenance, traceability, deterministic confidence, runtime metadata, and execution metadata.

## Explainability, provenance, and traceability

Profile confidence is derived explicitly from existing component confidence values. Provenance is retained from evidence, findings, and assessments. Traceability includes original evidence, finding, assessment, and signal identifiers. Source relationships are retained from identity-linking trace records.

## Runtime participation

`UnifiedIntelligenceVerticalSlice` runs GitHub, Twitter, Website, and Wallet source inputs through Identity Linking, Evidence Fusion, Finding Fusion, Assessment Fusion, and profile composition. The original canonical objects then execute through the existing compiler, Knowledge Graph, correlation, reasoning, automation, distribution, and execution engine. Runtime and Platform SDK remain unchanged.

## Future AI integration

Future AI reasoning may consume the immutable profile as input, but it must remain a separate layer. AI must not mutate canonical evidence or erase provenance, confidence rationale, or traceability.
