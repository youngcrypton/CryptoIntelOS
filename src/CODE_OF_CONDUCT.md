# Code of Conduct

CryptoIntel OS is committed to maintaining a welcoming and respectful community.

---

# Our Standards

Examples of positive behavior include

- Respectful communication
- Constructive feedback
- Helping others learn
- Professional collaboration

Unacceptable behavior includes

- Harassment
- Personal attacks
- Discrimination
- Spam
- Abuse

---

# Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Violations may result in warnings, temporary restrictions, or permanent removal from the community.

---

Together we can build a welcoming and productive open source community.
