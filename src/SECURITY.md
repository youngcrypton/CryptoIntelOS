# Security Policy

Security is an important part of CryptoIntel OS.

If you discover a security vulnerability, please report it responsibly.

---

# Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x | Yes |
| 0.1.x | No |

---

# Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities before they have been investigated.

Include:

- Description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots
- Logs
- Possible impact

---

# Response Process

Reported vulnerabilities will be:

1. Acknowledged
2. Investigated
3. Fixed
4. Released
5. Publicly disclosed if appropriate

---

Thank you for helping improve the security of CryptoIntel OS.
